# 🛡️ Zero-Knowledge Vault

A secure, browser-based security tool and vault designed with client-side protection and robust backend logic. Developed as part of cybersecurity engineering studies to ensure encrypted data privacy and secure management.

## 🚀 Features
* Zero-Knowledge Architecture: Client-side security layers ensuring privacy and integrity.
* Secure Backend Integration: Handled via custom PHP scripts (db.php, index.php, save.php) and database synchronization.
* Modern Interface: Styled with clean CSS for an optimal user experience.

## 🛠️ Tech Stack
* Frontend: HTML5, CSS3, JavaScript
* Backend: PHP, MySQL
* Environment: XAMPP / Apache Local Server
